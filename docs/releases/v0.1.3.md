## Fixed

- **Civilizations no longer take over notes from Ultimate Countries.** A civilization that is also a modern country (Argentina, Brazil, Canada, Australia and 18 more) was given the same note ID as its card in [Ultimate Countries](https://github.com/AminFadaee/Ultimate-Countries), so importing one deck replaced the other's note, and importing with "Merge note types" turned on mixed the two note types together. Civilizations now have IDs of their own.

## Upgrading

- Every civilization note gets a new ID, so importing this release adds the civilizations as new notes beside the old ones, and their review history stays with the old notes. Delete the old ones: in the browser, search `note:"Total History civilization"` and sort by Created to pick out the older notes. People keep their notes and progress.
- Import with "Merge note types" turned off.
